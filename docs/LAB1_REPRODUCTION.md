# MLHAT_17 — Lab 1 benchmark reproduction (partial, independent)

**Purpose:** Run our own Stage 2/3 model on actual named benchmark datasets from the published MLHAT paper. This is NOT a claim that our Stage 3 is the published MLHAT algorithm. The author repository is for verification only; do not copy its implementation.

## 1. Source and paper targets

Paper: Aurora Esteban et al., *Hoeffding adaptive trees for multi-label classification on data streams*, 2024, **Table 3** (dataset statistics), **Table 6** (per-dataset example F1), Section **4.1.3** (prequential evaluation, forgetting factor 0.995, evaluation every 50 observations).

| Full dataset | Instances | Raw features | Labels | Published MLHAT Example-F1 (Table 6) |
|---|---:|---:|---:|---:|
| Flags | 194 | 19 | 7 | 0.605 |
| Emotions | 593 | 72 | 6 | 0.446 |
| Yeast | 2417 | 103 | 14 | 0.588 |

Dataset source: https://www.uco.es/kdis/mllresources/ (get the **full** Mulan `.arff` + `.xml` or **full** MEKA `.arff`, not a train/test subset). Alternative repository: https://cometa.ujaen.es/datasets/ . If a dataset file has the wrong number of rows/features/labels, script intentionally refuses comparison.

The reference numbers in Table 6 apply to the original MLHAT, not to our model. Results on the 3,000-sample synthetic demo are ineligible to compare to these figures.

## 4. Comparing with the paper properly

- The algorithm Stage 3 is an approximation, not exact MLHAT: approximate ADWIN detector, alternate-branch comparison not Equation (16), not all paper bootstrapping, branch probabilities or prediction blending.
- Our nominal features are one-hot expanded; numeric features are not normalized. Original paper may implement categorical splits differently.
- The paper uses prequential evaluation (test before training) with forgetting factor 0.995. We record **both cumulative and EWMA Example-F1** for transparency, because a simple final EWMA value is not proven equal to the authors' final aggregation.
- The ARFF order and exact source variant matter. 194 observations (Flags) are smaller than the `grace_period` of 200, so no split is expected under the basic Stage 2 tree.
- *Indicative* delta to paper = team EWMA F1 − published Example-F1. This is **not** a proof of exact reproduction and must not be reported as a controlled model-vs-model improvement.
- We must complete full-algorithm parity and metric/protocol parity before marking any table row as an exact reproduction.
